# dsh-meridian（经络 Meridian）

> **AI 的运行时事实接口 + 自校验标尺。**
> AI 是第一读者，人是第二读者——人做决策，AI 做校验。

## 它解决什么问题

AI 写代码太快，人读不过来；而 AI 自己也**看不见代码的运行时态**——
它只能读到日志文本，却无法知道「这次运行到底符不符合预期」。
本插件把运行期痕迹变成**带证据的运行时事实**，并（规划中）与「标尺」比对给出判定。

## 第一战场与第二战场

| 战场 | 问题 | 交付 |
|---|---|---|
| 第一：AI 代码验收 | 我这次改动，运行起来是不是我想的那样？ | 事实 + 意图 → 判定 + 证据 |
| 第二：线上排查 | 哪里可以优化？ | 耗时的可归因证据，而非经验猜测 |

## 当前进度（MVP-0 已完成并验证）

- ✅ **格式即声明**：把 logback pattern 编译为解析器，根治「格式锁定」。
- ✅ **覆盖度披露**：任何结果都附带「解析率 / 漏网数 / 漏网样本」。
- ✅ **失败必显式**：解析失效时 `verdict = failed`，绝不把空结果当作「无问题」。
- ✅ **证据绑定**：每条事实带 `来源 + 行号 + 原文片段`。
- ✅ **真实语料验证**：DSEDT 项目 2026-09-14 真实测试产物。

### 实证（本项目最有价值的一条证据）

被观测项目原有的链路回溯实现把日志格式硬编码成正则：

| 语料 | 原实现（硬编码正则） | 本插件（格式声明） |
|---|---|---|
| 真实测试态日志 144 行 | **命中 0 行（0%）** | **命中 179 / 390 行，漏网 0** |
| 生产态格式样本 | 命中 | 命中（并抽出 traceId） |

> 结论：**格式一变即静默失效，而且没有任何机制告诉我它失效了。**
> 这正是「AI 需要一个标尺」的最硬证据——AI 看到空结果会说「没问题」，
> 真相是解析器一条都没解析出来。

## 快速开始

```bash
node scripts/check-all.mjs                              # 门禁：注释 + 类型 + 测试
node --import tsx scripts/dev-ingest.ts <日志文件>        # 把日志跑成事实 + 覆盖度
node --import tsx scripts/dev-ingest.ts <日志文件> --json out.json --case <traceId>
```

## 目录结构

```
src/features/   砖块：事件模型 / 格式编译 / 规则引擎 / 摄取
src/packs/      数据：被观测系统的接入声明（格式 + 规则）
tests/          回归测试（含真实语料与反证实验）
scripts/        门禁与开发驱动
```

## 路线图

1. **标尺（下一步）**：基线指纹 + 期望（AI 声明的意图） → 判定（四类偏离语义）。
2. **工具面**：`mer_ingest` / `mer_facts` / `mer_verdict` 注册为 DSH 工具（AI 第一读者）。
3. **第二实例**：IHM2（PHP/Laravel）适配器——验证「运行时态跨语言」这一主张。
4. **采集端升级**：把「写给人看的文本」换成结构化事件（保留人类可读输出），根治双重表示。
